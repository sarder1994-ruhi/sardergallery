# সরদার গ্যালারি (Sarder Gallery) - ই-কমার্স প্ল্যাটফর্ম

**সরদার গ্যালারি (Sarder Gallery)** বাংলাদেশের একটি পূর্ণাঙ্গ, আধুনিক ও সুরক্ষিত বেবি ও শিশুদের পণ্যের ই-কমার্স অ্যাপ্লিকেশন। এটি প্রিমিয়াম বেবি রকার, বেবি দোলনা, বেবি সোফা, ফিডিং ও কেয়ার সামগ্রীর কেনাকাটায় একটি নির্ভরযোগ্য কেনাকাটার অভিজ্ঞতা প্রদান করে।

---

## ১. আর্কিটেকচার ও প্রযুক্তি

- **ফ্রন্টএন্ড:** React 19, TypeScript, Tailwind CSS, Lucide Icons, Canvas Confetti
- **ব্যাকএন্ড:** Node.js, Express REST API
- **ডাটাবেজ ও পারসিস্টেন্স:** ট্রানজ্যাকশনাল অ্যাটমিক ডিস্ক স্টোরেজ (`data/db.json`), স্বয়ংক্রিয় ব্যাকআপ ও এক্সপোর্ট
- **সিকিউরিটি ও অথেনটিকেশন:** ক্রিপ্টোগ্রাফিক PBKDF2 (100,000 rounds, 64-byte key) সল্টেড হ্যাশিং, টোকেন-বেসড সেশন, সিকিউরিটি অডিট লগ
- **ক্যাশ অন ডেলিভারি (COD):** ১০০% স্বয়ংসম্পূর্ণ ক্যাশ অন ডেলিভারি এবং রিকনসিলিয়েশন ব্যবস্থা

---

## ২. প্রাথমিক অ্যাডমিন একাউন্ট ও সিকিউরিটি

ব্যবসার মালিকের চাহিদা অনুযায়ী প্রাথমিক অ্যাডমিন তথ্য কনফিগার করা হয়েছে:

- **লগইন আইডি:** `admin@sarder`
- **প্রাথমিক পাসওয়ার্ড:** `123456`
- **লগইন রুট:** `/` (হেডার বা ফুটারের অ্যাডমিন বাটনে ক্লিক করে সরাসরি প্রবেশ করা যাবে)

> **গুরুত্বপূর্ণ সিকিউরিটি বৈশিষ্ট্য:**
> প্রথমবার লগইন করার পর সিস্টেম স্বয়ংক্রিয়ভাবে একটি বাধ্যতামূলক পাসওয়ার্ড পরিবর্তন স্ক্রিন প্রদর্শন করবে। অ্যাডমিনকে অবশ্যই কমপক্ষে ৬ অক্ষরের নতুন গোপন পাসওয়ার্ড নির্ধারণ করতে হবে। পরিবর্তন করার পর ডাটাবেজে নতুন হ্যাশ সংরক্ষিত হবে এবং আগের পাসওয়ার্ড বাতিল হয়ে যাবে।

## ৩. প্রকল্প চালু ও ডেভেলপমেন্ট নির্দেশিকা

### নির্ভরতাসমূহ ইনস্টল করতে:
```bash
npm install
```

### অটোমেটেড টেস্ট রান করতে:
```bash
npm test
```
*(এটি পাসওয়ার্ড হ্যাশিং, ইনভেন্টরি লক, জেলা অনুযায়ী ডেলিভারি ফি, কুপন ছাড় এবং অর্ডার ট্রানজ্যাকশন স্বয়ংক্রিয়ভাবে যাচাই করে)*

### লোকাল ডেভেলপমেন্ট সার্ভার চালু করতে:
```bash
npm run dev
```
সার্ভারটি `http://localhost:3000` এ চালু হবে।

### প্রোডাকশন বিল্ড তৈরি করতে:
```bash
npm run build
npm start
```

## ৪. প্রধান প্রধান কার্যপ্রণালী

### ক. কাস্টমার ফ্রন্টএন্ড ও শপিং
- আকর্ষণীয় প্যাস্টেল বেবি থিম ডিজাইন এবং বাংলা টাইপোগ্রাফি
- হিরো ব্যানার ক্যারোসেল (অ্যাডমিন থেকে পরিবর্তনযোগ্য)
- সকল পণ্য ব্রাউজার, ক্যাটাগরি ও লাইভ সার্চ
- কুপন কোড ব্যবহার (`SARDER10`, `BABYJOY`, `FREESHIP`)
- রিয়েলটাইম স্টক চেক এবং ওভারসেলিং রোধ

### খ. চেকআউট ও বাংলাদেশ ডেলিভারি সিস্টেম
- বাংলাদেশের সকল ৬৪টি জেলার তালিকাভুক্ত ড্রপডাউন
- ঢাকার ভেতরে ডেলিভারি চার্জ: **৳৭০**
- ঢাকার বাইরে ডেলিভারি চার্জ: **৳১৩০**
- **৳২,৫০০** বা তদূর্ধ্ব অর্ডারে সারা দেশে **ফ্রি ডেলিভারি**
- সম্পূর্ণ কার্যকরী ক্যাশ অন ডেলিভারি (COD)
- ১১ ডিজিটের মোবাইল নম্বর যাচাইকরণ

### গ. অর্ডার ট্র্যাকিং ও চালান প্রিন্ট
- প্রতিটি অর্ডারের জন্য ইউনিক অর্ডার নম্বর (যেমন: `SG-2026-1001`)
- কাস্টমার ট্র্যাকিং পেজ থেকে বর্তমান স্ট্যাটাস দেখার সুবিধা
- স্ট্যান্ডার্ড প্রিন্ট ফ্রেন্ডলি চালান / ইনভয়েস প্রিন্ট করার সুবিধা
- সরাসরি হোয়াটসঅ্যাপে অর্ডার কনফার্মেশনের মেসেজ পাঠানোর লিংক

### ঘ. অ্যাডমিন ড্যাশবোর্ড
1. **ওভারভিউ ড্যাশবোর্ড:** বিক্রয় মূল্য, মোট অর্ডার, বাকি COD, স্বল্প স্টক পণ্যের তালিকা।
2. **পণ্য ব্যবস্থাপনা:** নতুন পণ্য তৈরি, ছবি আপলোড, মূল্য ও ডিসকাউন্ট নির্ধারণ, স্টক আপডেট।
3. **অর্ডার কন্ট্রোল:** স্ট্যাটাস পরিবর্তন (পেন্ডিং -> কনফার্মড -> প্রসেসিং -> প্যাকড -> কুরিয়ার -> ডেলিভার্ড)।
4. **COD রিকনসিলিয়েশন:** কুরিয়ার বা গ্রাহকের কাছ থেকে টাকা আদায় রেকর্ড করা।
5. **কুরিয়ার ইন্টিগ্রেশন:** পাঠাও (Pathao), স্টিডফাস্ট (Steadfast) এবং রেডএক্স (RedX) এপিআই কনফিগারেশন অথবা ম্যানুয়াল কনসাইনমেন্ট ট্র্যাকিং।
6. **পেমেন্ট গেটওয়ে সেটিংস:** বিকাশ মার্চেন্ট, নগদ ও এসএসএলকমার্স।
7. **ব্যাকআপ ও এক্সপোর্ট:** এক ক্লিকে সম্পূর্ণ ডাটাবেজ JSON ব্যাকআপ এবং অর্ডারসমূহ CSV ফাইলে ডাউনলোড।

## ৫. পরবর্তীতে নিজস্ব হোস্টিং বা ডোমেইনে স্থানান্তরের নির্দেশিকা (Migration Guide)

আপনি যখন পরবর্তীতে নিজস্ব ডোমেইন (যেমন: `sardergallery.com`) এবং নিজস্ব VPS বা ক্লাউড হোস্টিং (DigitalOcean, Hetzner, AWS, cPanel বা Render) ক্রয় করবেন:

1. আপনার নতুন হোস্টিং সার্ভারে Node.js v20+ ইনস্টল করুন।
2. সরদার গ্যালারির সম্পূর্ণ সোর্স কোড সার্ভারে ক্লোন বা আপলোড করুন।
3. `npm install` চালিয়ে ডিপেনডেন্সি ইনস্টল করুন।
4. `.env` ফাইলে আপনার ডোমেইন ও পোর্ট কনফিগার করুন।
5. `npm run build` দিয়ে প্রজেক্ট বিল্ড করুন।
6. `pm2 start server.ts --name sarder-gallery` অথবা `npm start` দিয়ে ব্যাকগ্রাউন্ডে সার্ভার সচল রাখুন।
7. Nginx বা Caddy ব্যবহার করে রিভার্স প্রক্সি এবং বিনামূল্যে Let's Encrypt SSL সার্টিফিকেট সেটআপ করুন।
8. প্রয়োজনবোধে অ্যাডমিন প্যানেল থেকে ডাউনলোড করা ব্যাকআপ JSON ফাইল নতুন সার্ভারের `data/db.json`-এ রিপ্লেস করলেই অতীতের সকল পণ্য, অর্ডার ও হিসেব হুবহু প্রতিস্থাপিত হয়ে যাবে।
